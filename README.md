# SMG Admin Panel

Admin CMS for Shomajgori Foundation — homepage content, founder modal, gallery, users.

**Production:** `https://admin.shomajgori.org`

## Setup

```bash
cp .env.example .env
# VITE_API_BASE_URL=https://api.shomajgori.org
# VITE_PUBLIC_SITE_URL=https://shomajgori.org
npm install
npm run dev
```

Runs on `http://localhost:5174`
